# Planning notes

Working notes for the `ai_bridge` module. They are kept in the repository for transparency and are
not shipped in the Forge package. User documentation is in [`../docs/`](../docs/).

| File | What it holds |
|------|---------------|
| `PROJECT.md` | What the project is for, scope and constraints |
| `ROADMAP.md` | Phases, their status, and the decisions log |
| `STATE.md` | Where things stand now |
| `BACKLOG.md` | Open work and candidate scope for the next release |
| `DOC-VERIFY-ITEMS.md` | Documentation claims not yet confirmed against a real PE |
| `phases/` | Plans for phases 1–4 |
| `field-tests/` | Dated evidence from testing against a real Puppet Enterprise |
| `releases/` | One record per Forge release: what was published and how it was verified |

Field-test notes describe a private test lab; host names and addresses are replaced with generic
names.
