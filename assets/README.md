# Sales overview graphic

`pe-llm-choice.png` is a widescreen presentation graphic intended for the README
and reuse in slide decks. Insert the original PNG and preserve its aspect ratio.

Flow: User → PE Infra Assist → LiteLLM (deployed by ai_bridge) → selected provider.
The provider rail represents alternatives, not broadcasting a request to all
providers. Provider examples are illustrative; this diagram does not claim each
integration has been validated by this module. Features, credentials, model
availability and compatibility vary by backend.

The visual uses a Perforce-inspired indigo palette. It is an AI-generated
community-module illustration, not an official Perforce sales asset. Provider
marks are illustrative brand references; use official supplied artwork for any
campaign that requires exact brand-lockup compliance.

Brand direction reference: [Perforce brand refresh](https://www.perforce.com/perforce-brand-refresh)
(indigo primary color) and [official color assets](https://brandfolder.com/perforce/public-colors).
